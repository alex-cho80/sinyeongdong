# 네이버 이미지의 구획 내부 진행 표시 — 2026-10-05

네이버 이미지 원본과 지번·동의·방문 데이터는 유지한다. 도면 간 자동 변환 좌표만으로 그리면 도로와 구획 밖으로 밀리는 경우가 있어, 표시 가능한 각 지번에 대해 이미지의 구획 안쪽 참고점을 직접 대조한다. 현재 132개 공통 지번 참고점 중 네이버 이미지에 127개를 표시한다.

`lib/naver-marker-layout.ts`는 네이버 이미지(861×925)에서 확인한 내부 표시 위치와 좁은 구획용 반경을 관리한다. 기본 반경 5.5px, 좁은 칸 2.6px, 매우 좁은 칸 2px(228-1은 1.1px)를 사용하며 선택·키보드 강조 테두리는 상태 원 안쪽에 둔다. 혼재 색상 띠는 기본 원 안쪽에 그린다. 이는 이미지 배치용 좌표이며 법적 지적 경계나 측량 결과가 아니다.

27-13, 214-105, 239-2, 239-17은 네이버 이미지에서 독립 구획 연결을 확정하지 못해 다른 지번의 칸에 동그라미를 임의로 넣지 않는다. 네이버 위치 확인 목록에 사유를 표시하고 조사 목록·기존 도면 참고점·저장 기록은 유지한다. 특히 214-105와 214-106은 같은 칸의 숫자 판독 차이 때문에 네이버 지도에서는 214-106만 표시한다.

검증: 모든 표시 지번에 직접 대조한 위치가 있는지, 문제 구획의 내부 여유 영역에서 선택 테두리까지 벗어나지 않는지 확인했다. 원본 위에 원과 지번을 겹친 이미지로 육안 대조했다. 공통 지번 연결과 조사제외·공개 조회 권한에 대한 기존 검증도 유지한다.

## 전체 재점검 및 포커스 오류 수정

클릭 후 포커스 CSS가 투명 클릭 영역에도 3px 테두리를 적용하던 오류를 수정했다. 선택/키보드 강조는 상태 원 안쪽에만 표시하고 클릭 영역에는 테두리를 그리지 않는다. 네이버의 기존 표시 지번 128개를 북부·중앙·동부·남부로 나눠 원본과 확대 대조했으며, 223·226-1의 위치와 223·226-1·244의 표시 크기를 조정했다.

고시 도면은 기존 좌표들이 도로/다른 필지에 어긋나 있어 도면 자체에서 127개 내부 참고점을 다시 읽었다(`source-marker-layout.ts`). 새 첨부 도면의 214-46/48/49, 229번지 주변, 북동부 좁은 필지도 위치를 수정했다. 27-13, 214-106, 239-17은 새 첨부/고시 도면에서 독립 구획을 연결하지 못해 확인 목록으로 보낸다. 고시 도면에서 독립 위치가 없는 239-2도 확인 목록에 남긴다. 조사·동의·방문 기록은 삭제하거나 수정하지 않는다.

223은 지도별 실제 이미지에서 읽은 다각형으로 중심과 원 외곽의 경계 거리를 검증한다. 다른 지번은 확대 이미지 대조이며 법적 지적 경계 검증이 아니다.

네이버 228-1은 228-2와 구분되는 가느다란 띠 내부로 이동하고 1.1px 반경을 사용한다. 227-3은 기존 좌표가 226-1 구획에 겹쳐 네이버 위치 확인 목록으로 옮겼다. 기록은 유지하며 확인되지 않은 지번의 원을 다른 필지에 표시하지 않는다. 현재 네이버 표시 127곳, 위치 확인 5곳(전체 기존 미확정 목록은 별도)이다.
