# 네이버 이미지의 구획 내부 진행 표시 — 2026-10-05

네이버 이미지 원본과 지번·동의·방문 데이터는 유지한다. 도면 간 자동 변환 좌표만으로 그리면 도로와 구획 밖으로 밀리는 경우가 있어, 표시 가능한 각 지번에 대해 이미지의 구획 안쪽 참고점을 직접 대조한다. 현재 132개 공통 지번 참고점 중 네이버 이미지에 128개를 표시한다.

`lib/naver-marker-layout.ts`는 네이버 이미지(861×925)에서 확인한 내부 표시 위치와 좁은 구획용 반경을 관리한다. 기본 반경 5.5px, 좁은 칸 2.6px, 매우 좁은 칸 2px를 사용하며 선택 테두리는 반경+1.5px 안에 둔다. 혼재 색상 띠는 기본 원 안쪽에 그린다. 이는 이미지 배치용 좌표이며 법적 지적 경계나 측량 결과가 아니다.

27-13, 214-105, 239-2, 239-17은 네이버 이미지에서 독립 구획 연결을 확정하지 못해 다른 지번의 칸에 동그라미를 임의로 넣지 않는다. 네이버 위치 확인 목록에 사유를 표시하고 조사 목록·기존 도면 참고점·저장 기록은 유지한다. 특히 214-105와 214-106은 같은 칸의 숫자 판독 차이 때문에 네이버 지도에서는 214-106만 표시한다.

검증: 모든 표시 지번에 직접 대조한 위치가 있는지, 문제 구획의 내부 여유 영역에서 선택 테두리까지 벗어나지 않는지 확인했다. 원본 위에 원과 지번을 겹친 이미지로 육안 대조했다. 공통 지번 연결과 조사제외·공개 조회 권한에 대한 기존 검증도 유지한다.
